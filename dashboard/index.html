Getting Started

Two ways to explore this repository. Pick whichever suits you.

🗂️

Traditional Experience

Clone the repo and browse .java files directly — exactly like any GitHub repository.

git clone https://github.com/DivaQueen-dev/Java_Dsa.git
cd Java_Dsa
cd Arrays
javac ReverseArray.java
java ReverseArray
View on GitHub ↗
🌐

Interactive Experience

Clone the repo, then open the website in your browser — no server, no install needed.

git clone https://github.com/DivaQueen-dev/Java_Dsa.git
# Then open in your browser:
dashboard/index.html

🤝 How to Contribute

1
Fork & Clone

Fork the repo on GitHub and clone your fork locally.

2
Add your .java file

Place it in the appropriate topic folder (e.g., Sorting/YourAlgorithm.java).

3
Update data.js (optional)

Add an entry to make it visible in the interactive website.

4
Submit a Pull Request

Open a PR with a brief description of what you added or improved.
