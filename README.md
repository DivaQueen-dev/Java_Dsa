## 📖 What Is This?

`Java_Dsa` is a growing collection of **Core Java programs and Data Structures & Algorithms** implementations — organized, documented, and paired with an interactive companion website.

This is **not a course or bootcamp**. There are no lessons, no chapters, no forced learning paths.

Instead, think of it as a well-organized practice repository with two equally valid ways to explore it:

| 🗂️ Traditional Experience | 🌐 Interactive Experience |
|--------------------------|--------------------------|
| Clone and browse folders directly | Open the companion website locally |
| Read raw `.java` files | Browse topics with explanations & code viewers |
| Navigate through GitHub as usual | Search instantly, view complexity tables |
| Complete freedom, zero friction | The same content — just more beautiful |

> **The repository is always the source of truth. The website is an optional interface built around it.**

---

## ✨ Why This Exists

Browsing a practice repository is useful — but it can be visually overwhelming, especially when there are hundreds of Java programs across 15+ topic folders.

This project solves that by providing two equally valid paths:

- **Clone and code** — explore just like any GitHub repository
- **Open the website** — browse the same content through a clean, searchable interface with brief explanations, complexity tables, and one-click access to online playgrounds

Neither path is better. Use whichever fits your workflow.

## 🌐 Interactive Companion Website

The `dashboard/` folder contains a lightweight, zero-dependency interactive website for exploring this repository.

**No server. No build step. Just open `dashboard/index.html` in any browser.**

### What it offers

- 🔍 **Instant Search** — find any topic or program by name
- 📖 **Concept Overviews** — short explanations with real-world analogies
- 📊 **Complexity Tables** — time & space complexity for every operation
- ⚖️ **Pros & Cons** — trade-offs for each data structure
- ☕ **Code Viewer** — clean, syntax-highlighted code for every `.java` file
- 🔗 **Practice Links** — one-click to an online Java playground
- 🌙 **Dark Mode** — because 2 AM is peak learning time

## 🚀 Quick Start

```bash
# 1. Clone the repository
git clone https://github.com/DivaQueen-dev/Java_Dsa.git
cd Java_Dsa

# 2. Run any Java program directly
cd Arrays
javac ReverseArray.java
java ReverseArray

# 3. Open the companion website (optional)
# Open dashboard/index.html in your browser
```

→ See [GETTING_STARTED.md](./GETTING_STARTED.md) for the full setup guide.

Contributions are welcome! Whether you want to add a new program, improve an existing solution, or enhance the website — all pull requests are appreciated.
