## 📖 Welcome to my codebase!

Hey! I'm Diva. `Java_Dsa` is where I dump all my **Core Java programs and Data Structures & Algorithms** implementations. 

This isn't some rigid course or bootcamp repo. It's just my personal digital notebook. I built this to keep my code organized, document my progress, and make studying a little less boring. 

You can explore this repo in two ways:

| 🗂️ Traditional | 🌐 Interactive (My Favorite) |
|----------------|------------------------------|
| Clone and browse folders directly | Open the companion React website locally |
| Read raw `.java` files | Browse topics with my personal notes & code viewer |
| Navigate through GitHub | Search instantly, see complexity tables |
| Just code | The same content, just way prettier ✨ |

---

## ✨ Why I Built This

I realized that staring at a generic list of Java files on GitHub gets overwhelming fast. Especially when there are hundreds of them across 15+ topic folders!

So, I built a minimalist dashboard to make finding and reviewing my code easier. 

- **Clone and code** if you just want the raw files.
- **Open the dashboard** if you want to read my short explanations, check out time/space complexities, and view the code with syntax highlighting.

## 🌐 The Dashboard

I built a companion website in the `dashboard-react/` folder. It's a React app that I use to browse my own repo.

### What's inside:
- 🔍 **Instant Search** — find any topic or program instantly.
- 📖 **My Notes** — short explanations with real-world analogies that make sense to *me*.
- 📊 **Complexity Tables** — time & space complexity for every operation.
- ☕ **Code Viewer** — clean, syntax-highlighted code.
- 🌙 **Dark Mode** — because who codes in light mode?

### How to run it:
```bash
cd dashboard-react
npm install
npm run dev
```
